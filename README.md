# EOM firmware builds

- `eom3k-eom-wifi-usb-fixes-*.bin`: patched builds (USB pressure + Wi-Fi fixes, plugins compiled out).
- `firmware-stock-v2.1.0-rc.1.bin`: unmodified official Maus-Tec v2.1.0-rc.1, downloaded from
  https://github.com/MausTec/edge-o-matic-3000/releases/download/v2.1.0-rc.1/firmware.bin
  (rollback image). SHA-256 in the matching .sha256 file.

Install either by copying it to the SD card root and choosing it in the EOM update menu.
